# Rules

- Four fixed lenses, one parallel agent each: contradictions & incomplete items, build readiness, redundancy & cleanup, clarity & vision.
- Every auditor has explicit push-back license: challenging the docs' decisions is in scope, rubber-stamping is not.
- Findings must cite file and line (or section); no finding without an anchor.
- One consolidated report, ranked by severity, duplicates merged across lenses.
- Read-only: auditors never edit the docs; fixes are a separate, user-approved step.
- Works on spec folders, project docs, and KB notes alike.
