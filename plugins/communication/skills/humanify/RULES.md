# Rules
- Em dash (—) is forbidden, zero tolerance. Scan the output before returning it; rewrite if any remain.
- Strip AI-tells: vague attribution, rule-of-three, inline-header lists, bold-mechanically, title-case headings, emoji, sycophancy, signposting ("let's dive in"), excessive hedging.
- Don't just remove patterns — add real voice: opinions, varied sentence rhythm, first person where it fits.
- Preserve the core meaning and the intended tone (formal, casual, technical).
- Finish with an anti-AI audit pass: ask what's still obviously AI, then fix it before presenting the final version.
