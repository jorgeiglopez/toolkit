# Rules
- Cut first, add back only if meaning suffers.
- Active voice, name the actor; one idea per sentence.
- Cap ~25 words/sentence, ~4 sentences/paragraph — beyond that, break or convert to a list.
- Delete filler and hedges outright; replace wordy phrases with the tight one-word form.
- Cut AI-tells (crucial, seamless, delve, testament, etc.) on sight.
- Cut 10% on every second pass. Stop only when cutting starts to hurt meaning.
